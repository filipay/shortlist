## v1.0 MVP (Shipped: 2026-10-15)

**Phases completed:** 9 phases, 82 plans, 203 tasks

**Known verification overrides:** 22 newly acknowledged, 0 carried forward from a prior close (see STATE.md Deferred Items); all 9 phases read `verification_status=stale` at the boundary (later phases legitimately edited shared `covered_files`, so earlier phases' `covered_digest` fingerprints no longer match) — closed by explicit user override on 2026-10-15 ("Proceed anyway"), not by rewriting the digests.

- Hardened ingest boundary — exact code-point truncation, PII dropped and never logged — plus four falsifiable platform guards: no credential path, no remote asset, a universal auth seam, and every limit read from Settings.
- A TTL-cached liveness probe per board, a `/health` that answers 200 with a dead opencode server and a dead database, a visible per-source health strip, and an opencode discovery client whose plaintext-credential redaction boundary is proven by a sentinel test.
- Survival signals S1–S6 with every boundary read from Settings, a real politeness ledger written by the pipeline, and both operator gates passed — the dated verdict is honestly PROVISIONAL at 1 run on 1 day, and the gates exposed seven real defects (including a DataFrame-iteration bug that collapsed a full page to one blank listing) which are fixed with regression tests.
- Named searches with per-kind rule forms, version-stamped edits, a pre-run capability report, and a per-search "Run this one" — wired into one shared pipeline callable.
- One schema-constrained call now completes through the `LLMBackend` port against a fake transport and returns a validated typed `ProbeResult`, with the whole wire contract pinned in `app/llm/contract.py` and an operator button on `/settings` that records the full outcome as a single `llm_calls` row.
- The opencode structured-output wire vocabulary is now pinned by a committed `/doc` slice and a default-lane test that fails on any code-side rename with no server running, with a negative control against adaptive clients and an operator live lane that reports server drift by pointer.
- Every way a structured call can fail now produces a classified, counted outcome — `ok`/`invalid`/`timeout`/`error` plus an operator-facing cause and an honest attempt count — and a truncated payload salvages through an explicit allow-list while a genuine mismatch still fails loudly.
- `llm_calls.server_version` is now a real, nullable, queryable column that the ORM mirrors, the audit writer round-trips, and the `/settings` probe read renders — so a future model/version regression is traceable to the opencode server that produced it (D-12 / M9).
- The three Phase-3 opencode ceilings are now real configuration: the config guard asserts them, a patched environment overrides them, the container forwards them (plus the previously unforwarded `OPENCODE_TIMEOUT_SECONDS`), and `.env.example` documents them.
- Success criterion 4 is now structural: untrusted content has no channel into `system`, tools are denied by default through the server's documented `permission` ruleset, the deny is observed on every call rather than assumed, and no LLM HTTP or process path exists outside `app/llm/`.
- An instruction-like listing is now recorded as counts-only evidence on the listing and flagged in the queue, a clean listing stays NULL, and `_finish` can record the LLM counters Phase 5 will supply — while the pipeline remains completely LLM-free (D-49).
- An omitted retry argument now honours `OPENCODE_MAX_RETRIES`, an explicit tool grant reaches the message body, and a broken model payload is an attributable `invalid` outcome — closing the phase BLOCKER plus two adapter warnings on the trust-boundary path.
- Pinned the session permission deny-rule shape against `/doc` drift, made a raising LLM backend auditable with an honest 500, and proved the T-3-21 nullable guard survives a clean re-ingest.
- Restored the internal `StructuredOutput` tool the session deny was stripping, moved the shipped default model to one that honours a forced tool call, made a structured failure name its cause, and proved the fixed path with a real end-to-end live call.

- A validated `cv.yaml` fact store with stable enumerated IDs, a byte-deterministic LaTeX renderer whose single Jinja `finalize` callback escapes every interpolated value, and a committed golden baseline that fails the build on any renderer change
- The two compiled PDFs — the human's fixture and the rendered one — are proven to carry the same organisation, title, date and bullet facts under a strict membership predicate with a mutation control that fails, and `cv_versions` gains its first writer so every rendered artefact can name its revision.
- A bounded, human-reviewed LaTeX-to-fact-store importer with a counts-and-names report, a re-runnable spike script, an operator compile runbook, and a dated PARTIAL verdict that names the real-document trigger instead of claiming a measurement
