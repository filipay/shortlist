<objective>
Close GAP C (WR-01): make the tailoring generate path honour its own audit contract and turn a raised backend transport error into a typed refusal instead of an unhandled 500.

Purpose: `app/pipeline/tailor.py:217-242` documents that `tailor_listing` "never raises for a model failure" and that "every call writes exactly one llm_calls row", but the `complete_structured` call sits in a try with only `_release()` in finally and the `record_llm_call` after the call — so a raise skips the promised audit row (the attempt becomes invisible) and then escapes the generate route (`app/api/tailoring.py:370-384`) as a bare 500. The audit trail is the cost and honesty surface (D-119 / D-12); a failed-but-attempted call that leaves no row is exactly the repudiation the ledger exists to prevent.

Output: a `tailor_listing` that records one `purpose="tailor"`, `status="error"` row on the exception path (class name only, no message), logs only the class, releases the shared in-flight slot, and returns `None`; the generate route's typed 502 `tailoring_failed` refusal reached instead of a 500; and the pipeline and route tests that pin the audit row, the typed refusal, the class-only redaction and the released slot.
</objective>
