sanitised once, PII is structurally absent, no credential path exists, every route carries the auth
seam, every limit is configuration, and every UI asset is local.

is the same argument the migration checklist makes.

guards.

   output for two texts differing only in their PII is identical.
5. `tests/domain/test_sanitize_edge.py` — a null and an empty description each return a deterministic
   empty string without raising; a description of exactly `max_chars` is unchanged; one of
   `max_chars + 1` is truncated to `max_chars`; a multi-byte (accented/CJK) string truncates by

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| job board text → database | sanitise is the single gate; PII must not cross it |
| template ↔ browser | listing text is rendered server-side with autoescape; no remote asset origin |
| route → identity | every route resolves an identity through the seam, even though v1 always returns the local user |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-23 | Information Disclosure | recruiter PII in the description or a log line | high | mitigate | Pure PII removal at the ingest boundary; `RawListing` has no such field; only a count is recorded; asserted by `tests/test_sanitize_pii.py` (including a `caplog` scan) and plan 01-02's schema test |
| T-01-24 | Information Disclosure | a credential or session path appearing in an adapter | high | mitigate | `tests/test_no_credentials.py` fails on any credential read or session constructor under `app/` |
| T-01-25 | Tampering | XSS through listing text | high | mitigate | Autoescape on, no `|safe`; the template scan and the render tests in plan 01-03 cover the surface |
| T-01-26 | Information Disclosure | remote asset origin leaking usage to a third party / breaking offline use | medium | mitigate | `tests/test_no_cdn.py` asserts local-only assets |
| T-01-27 | Elevation of Privilege | a route added later without the identity seam | medium | mitigate | `tests/test_auth_seam.py` makes a seam-less route a test failure |
| T-01-28 | Tampering | a threshold hard-coded, defeating the config requirement and the ban-risk envelope | medium | mitigate | `tests/test_config.py` asserts the values are read from `Settings` and are env-overridable |
| T-01-SC | Tampering | package installs | low | accept | No new dependency |
</threat_model>
