<objective>
Turn the 9-item ROADMAP migration checklist from prose into failing-loud assertions, and pin the two
schema properties the phase's ethics and search behaviour depend on: PII cannot be represented, and
the FTS5 index is actually maintained by its triggers.

Purpose: the migration is one-way; this plan is the phase's first non-test gate made executable. A
checklist item that is only prose gets "we'll add it when we need it" (PITFALLS P8/Pitfall 9), and a
missing FTS trigger silently diverges the index so search misses newly inserted rows (PITFALLS M4).

Scope note: the edge probe could not classify `SRC-10` (boundary / precision rows). It is treated as
a flagged assumption — see the plan's `<flagged_assumptions>` block; the requirement is additionally
pinned by the negative schema test below.
Output: `tests/db/test_migration_contract.py` (all 9 items), `tests/db/test_no_pii_columns.py`,
`tests/db/test_fts_triggers.py`.
</objective>
