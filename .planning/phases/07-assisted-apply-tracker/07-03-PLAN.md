</objective>

Add `app/verify/screening.py` exposing `ground_screening_answers(facts: CvFacts, listing_text: str, response: ScreeningDraftResponse) -> list[ScreeningVerdict]`, each verdict carrying `{question, answer, grounded_evidence_ids, unsupported, warnings}`. The primary check is structural: intersect each answer's `evidence_ids` byte-exact with `set(app.domain.cv.iter_fact_ids(facts))`; an id not in the set is dropped from `grounded_evidence_ids` and adds a warning naming it. An optional advisory lexical band may reuse `app.verify.grounding.band_for` with the EXISTING Settings thresholds (`tailoring_grounding_threshold`/`tailoring_grounding_review_threshold`) and must never flip the warning state. State the two residuals honestly in the module docstring (a novel-digit is a warning, not a block; fabricated prose with no novel digit is not caught by this check and is mitigated by the copy-only posture) — no absolute guarantee. `tests/verify/test_screening.py`: grounded passes; unknown evidence id warns naming the id; fabricated metric digit warns naming the token; a legitimate paraphrase containing a known digit passes; plus the CONVENTIONS rule-4 property/parametrized test that mutates the answer to embed other entities' identifiers and asserts the checker still passes.</action>
