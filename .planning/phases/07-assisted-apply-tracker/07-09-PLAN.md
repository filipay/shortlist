<objective>
Close G-07-4: every download affordance must yield the artifact it labels.

Purpose: `GET /listings/{id}/cv/pdf` ignores any version and always selects the latest ok artifact. Three affordances therefore all resolve to the same file: the persistent Latest CV control, the post-compile banner's own download anchor, and every ok row under 'Previous compiles'. Clicking an older row downloads the newest PDF, and after a compile the user sees two identical controls. The served content is never wrong; the affordance is.
Output: an optional artifact id on the route with a listing-ownership check, a single latest download control, and per-row version-exact links.
</objective>
