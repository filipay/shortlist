<objective>
Close G-07-1: recording an application from the apply package must leave the user on the styled tracker page.

Purpose: the apply page's record form is a plain (non-HTMX) form, so the browser does a full-page POST. The record route currently returns `applications_list.html` — a bare table fragment with no `<head>`, no stylesheet and no nav — so the styled page is replaced by an unstyled fragment. The design is unwired: the apply page owns the record form but has no tracker swap target, and the tracker page owns `#application-list` but has no record form. The established codebase precedent is a Post-Response-Get 303 redirect (`app/api/tailoring.py`'s delete route).
Output: a 303 redirect from the record route and regression tests that assert the redirect and the styled landing page.
</objective>
