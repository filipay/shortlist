<objective>
Prove the phase's integrity spine end to end at thin depth: an application is recorded for a listing, exactly one append-only event is written in the same transaction, and the tracker renders that application with its history.

Purpose: the tracker's core contract — current state on the row, history in a trigger-enforced append-only table, every applied application linked to an exact `ok` artefact — is the phase's highest-risk design. Proving it on one path catches an architectural dead end before the apply package and drafting surfaces are built on top.
Output: migration 0006 (new tables + the `application_events` triggers), the application repository, and the working `/applications` tracker with record/transition/history routes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `/applications/*` | An untrusted form supplies a stage, an artefact id, a note and a next-action date. |
| application_repo -> `application_events` | The history table is append-only; the repository is the only writer. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
