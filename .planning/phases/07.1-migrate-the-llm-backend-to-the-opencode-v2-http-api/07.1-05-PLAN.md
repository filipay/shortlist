<objective>
Retarget the two operator-run live lanes to the V2 contract and make the in-app selftest report
V2 success honestly. The default lane is offline by construction, so the only place a real
`generate` and a live spec diff can be proven is the operator lane — and the selftest's
`Structured payload: present` line currently derives from the V1 `info.structured` key, which V2
does not have.

Purpose: D-150 requires the running server to match a supported contract *by test*, and D-145
requires model selection to be proven by a positive and a negative live `generate`. Without this
plan those checks would still be written against a dead contract.
Output: a V2 contract live lane (`/openapi.json` + `/api/info`), a retargeted positive/negative
live call lane, and a selftest whose success signal no longer depends on V1-only response keys.
</objective>
