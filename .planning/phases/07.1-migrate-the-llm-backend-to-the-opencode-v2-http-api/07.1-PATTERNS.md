## Pattern Assignments

### `app/llm/contract.py` (edit) — add the V2 group, keep V1 intact

**Analog:** `app/llm/contract.py` itself.

**Grouping pattern to copy** — the module already groups wire names under `# --- … ---`
section banners with a per-constant rationale comment (lines 21, 32, 46, 57, 74). D-148
requires **two clearly separated groups**: keep every existing banner and add a
`# --- V2 contract (opencode 2.0.x) ---` block. Reinforce with an explicit "V1 (retained)"
header on the existing block so neither absorbs the other's spelling.

**Existing header style (lines 21-30):**
```python
# --- servers / endpoints ------------------------------------------------------
DOC_PATH = "/doc"
SESSION_PATH = "/session"
#: The wire spelling WE build the message URL with.
MESSAGE_PATH = "/session/{session_id}/message"
...
MESSAGE_DOC_PATH = "/session/{sessionID}/message"
```

**What to add (RESEARCH Pattern 3 table):** `OPENAPI_PATH`, `INFO_PATH`,
`V2_SESSION_PATH`, `GENERATE_PATH`, `GENERATE_RESPONSE_PATH = ("data","text")`,
`MODEL_REF_FIELDS = ("id","providerID")`, `V2_SESSION_RESPONSE_PATH = ("data","id")`.

**Deviations the phase legitimately needs:**
- The `__all__` list (lines 112-144) grows; keep it exhaustive (the contract tests import
  by name).
- V2 has **no** `FORMAT_*`/`STRUCTURED_*`/`PERMISSION_*` constants — do not add twins. The
  existing V1 constants stay (D-148).
- Keep the module `import`-free guarantee (docstring lines 15-16): V2 constants are plain
  literals, no new import.

### `app/llm/builders.py` (edit) — add `to_generate_prompt` (V2)

**Analog:** `to_message_body` (lines 87-143) and `_normalize_json_schema` (lines 43-72) in
the same file.

**Purity contract to copy (module docstring lines 1-17):** builders are pure, no I/O, no
state, so the snapshot test can pin them with no server running. `to_generate_prompt` must
honour the same contract.

**Schema-into-prompt pattern** — reuse `_normalize_json_schema` **unchanged** (D-142 /
RESEARCH Pattern 2). Its only `model_json_schema()` call site today is `to_message_body`
line 126; V2 adds a second call site, which is fine (the function is the single
normalizer, not the single caller):
```python
FORMAT_SCHEMA_FIELD: _normalize_json_schema(schema.model_json_schema()),
```

**Prompt-assembly shape (RESEARCH Pattern 2, verbatim ordering):** frozen `system` first →
`"Return a single JSON object matching exactly this JSON schema:\n"` +
`json.dumps(_normalize_json_schema(schema.model_json_schema()))` → hard `---` delimiter →
explicit untrusted-data directive → `"\n".join(parts)`. `parts` stays the only channel for
untrusted content (docstring lines 99-102); no argument may let request data reach `system`.

**Deviations the phase legitimately needs:**
- A new import of the V2 constant names; keep every key from `app.llm.contract` (D-54).
- The V1 `to_message_body`/`to_message_parts`/`to_session_body` stay untouched.
- `json.dumps` is a stdlib import — the module currently imports only `collections.abc`,
  `typing`, `pydantic`; add `json`.

### `app/llm/detection.py` (new) — surface detection (D-147; RESEARCH Pattern 1)

**No single exact in-repo analog exists.** The closest composite is two existing shapes:

1. **Pure decision function** → `app/llm/builders.py`: a small, dependency-light, no-I/O
   function (`_normalize_json_schema`, lines 43-72) that is exercised directly by a unit
   test (`tests/llm/test_schema_normalization.py`) with no socket. Structure detection so
   the *classifier* half is pure: `classify_surface(status_code, content_type, body) ->
   Literal["v1","v2","unknown"]` — a JSON body with `version` ⇒ V2, JSON with
   `healthy`/`version` ⇒ V1, else `UNKNOWN`. Never classify from a bare HTTP 200
   (RESEARCH Anti-Patterns; Pitfall P4).

2. **Process-local cache** → `app/probe/probe.py`: the established cache idiom in this repo
   is a module-level dict + a module-level `clear_cache()` for tests + the TTL read from
   settings on every use (lines 31-52, 75-93, `clear_cache` line 36):
   ```python
   _CACHE: dict[str, tuple[float, SourceStatus]] = {}
   def clear_cache() -> None: ...
   ```
   D-147's detection result is cached per `base_url` **and never caches `UNKNOWN`** (A2):
   the same `clear_cache()` test seam applies.

**Deviations the phase legitimately needs:**
- The probe half performs one `GET /api/info` (httpx) — the classifier half must stay pure
  so `test_v2_detection.py` can test `classify_surface` with no socket.
- It must import auth from the backend, not re-derive it: `_auth()` (opencode_server
  lines 246-254) already emits `httpx.BasicAuth("opencode", password)` exactly as V2 needs
  (RESEARCH "Don't Hand-Roll"). Either pass the built client in, or lift `_auth()` to a
  shared helper — do **not** add a second `BasicAuth` construction site.
- Depends only on `httpx` + `app.config` — the repo's "small dependency-light module"
  target (mirror `builders.py`'s stdlib-only discipline where possible).

### `app/llm/opencode_server.py` (edit) — V2 path + retargeted health

**Analog:** itself. Copy these existing structures verbatim and retarget the wire facts.

**`_failure` (lines 590-624)** — the single classified-failure constructor. D-137 adds
`ERROR_KIND_UNAUTHENTICATED = "unauthenticated"` to the D-52 taxonomy block (lines 77-86),
which is then passed into `_failure(error_kind=…)`. Copy the block comment discipline:
```python
ERROR_KIND_UNREACHABLE = "unreachable"
ERROR_KIND_TIMEOUT = "timeout"
...
#: Prefix for a non-200 response, e.g. `http_400`.

```
`_failure` keeps `raw=None` always and the bounded-excerpt discipline (`_bounded_excerpt`,
lines 627-635). No new field needed on `StructuredCallResult` for the error (error_kind
already carries it).

**`_auth` (lines 246-254)** — **unchanged.** Live-verified as the exact V2 mechanism
(RESEARCH "Don't Hand-Roll"). D-136 is enforced *by the caller*: empty password ⇒ fail
fast with `unauthenticated` and `attempts==0`, never issue the request.

**`health` (lines 272-292)** — retarget to `GET /api/info`, and **require JSON + `version`**
before returning `reachable=True`. The current body returns `reachable=True` on any
non-JSON 200 (lines 283-286) — that is the latent false positive on 2.0.26's SPA
(Pitfall P4). Keep it total (`reachable=False` on any exception, line 277-278).

**`_resolve_model` (lines 320-358)** — **retarget, do not delete** (Assumptions A1). It
already derives `(provider_id, model_id)` from discovery and fails loud
(`ERROR_KIND_MODEL_NOT_FOUND`) — preserve that exact shape; only the discovery payload
source changes to `/api/model` + `/api/provider`.

**`_create_session` (lines 360-397)** — copy the "value-not-exception" body-read pattern
(non-200 ⇒ `StructuredCallResult`, no usable id ⇒ `ERROR_KIND_INVALID_SESSION`). Retarget:
`V2_SESSION_PATH`, body built by `to_session_body` (V2 `Model.Ref`), and read the id at
`V2_SESSION_RESPONSE_PATH = ("data","id")` (Pitfall P2), keeping the `SESSION_ID_PREFIX`
check on `"ses"`.

**`complete_structured` (lines 399-587)** — keep the outer total-function envelope
(`try/except httpx.TimeoutException / httpx.TransportError / Exception`, lines 560-587),
the transport-retry loop (lines 485-545, bounded by `settings.opencode_max_retries`), the
`_failure(status=…, error_kind=…, attempts=…, started=…)` calls, and the "two retry layers"
docstring split (lines 417-429 — update it: the schema retry is now client-side, D-139).
Add the V2 inner loop: `POST {GENERATE_PATH}` → read `GENERATE_RESPONSE_PATH` →
`_extract_json` → `_salvage` → on `ValidationError` append the first pydantic error and
re-issue, ≤ `settings.opencode_structured_retry_count` times (D-139/D-140).

**`_salvage` (lines 690-708) / `_tolerant_validator` (659-687) /
`TOLERATED_SCHEMA_ERRORS` (93)** — **untouched** (D-142). `test_salvage.py` must stay green
verbatim.

**`parse_providers` (lines 164-216)** — retarget the payload key (`/api/model` `data`),
preserving the identifier-only copy and the docstring's "keys only, values never touched"
rule (D-11 redaction is a type-level property, not a re-derivation).

**`_extract_json` (new helper)** — no in-repo analog; it is new. Follow the house style of
the small pure helpers already in this module (`_bounded_excerpt` 627-635, `_elapsed_ms`
972-974): a short standalone function, docstring states the contract, no I/O. Strip
fences/leading prose, take the outermost brace block, then hand the string to `_salvage`
(D-141).

**Deviations the phase legitimately needs:**
- The V1 branch is retained inside `complete_structured` (D-148): dispatch on
  `detect_surface()` result; V2 and V1 arms both return `StructuredCallResult`.
- `model` telemetry changes meaning to the **configured** `settings.opencode_model` and
  provider/agent become `None` (D-143/D-144); `server_version` comes from `/api/info`.
- `__all__` (lines 998-1013) grows to export the new constant and `_extract_json` if the
  tests import it directly (the snapshot/discovery tests import module symbols by name).

### Failure-is-a-value (total functions)
