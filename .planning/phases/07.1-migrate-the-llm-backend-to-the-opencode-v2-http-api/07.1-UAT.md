## Gaps

gap_id: G-07.1-1
truth: "Clicking 'Draft answers' returns usable drafted answers the user can review and copy."
status: fixed-pending-live-confirmation
reason: "User reported: 'The drafting call did not return a usable response. Your existing drafts were kept.'"
severity: major
test: 3
root_cause: >
  `DRAFT_SYSTEM_PROMPT` asked for a top-level JSON ARRAY, but `_extract_json`
  (`app/llm/opencode_server.py:1189-1216`) can only ever return the first `{...}` object,
  so an array reply yielded one answer object and `_salvage(ScreeningDraftResponse, ...)`
  rejected it (`extra="forbid"`, required `answers: list[...]`) -> status=invalid ->
  drafting_failed. V1's server-side `format` coercion hid the contradiction; V2 removed it.
artifacts: [af17f8e, 65c80a6]
missing: ["live confirmation against a real opencode 2.0.26 server"]
