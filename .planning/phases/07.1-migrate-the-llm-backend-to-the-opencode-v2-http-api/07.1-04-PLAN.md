<objective>
Retarget model discovery to the V2 surface while preserving the redaction guarantees that make it
safe (D-146/D-09/D-11). The V2 session body needs a `providerID`, and `OPENCODE_MODEL` is only a
bare model id, so `_resolve_model` must keep deriving the provider from the server's own
discovery response — it is retargeted, never deleted (07.1-RESEARCH Assumption A1).

Purpose: `discover_models` is also the seam the deferred Settings model picker will consume
(D-146), so it must survive the migration with its redaction type-level property intact.
Output: a V2 discovery parse with the sentinel-redaction tests retargeted and green, the retained
V1 discovery path, and the cold-start retry.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| opencode discovery payload → app memory | `/api/provider` (and the V1 `/config/providers`) may carry a plaintext provider credential. |
| detected surface → endpoint choice | The wrong branch would read a V1 shape from a V2 endpoint or empty the model list. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-10 | Information Disclosure | `parse_v2_models` / `discover_models` | high | mitigate | Copy only `(provider_id, model_id)`; parse into `ProviderModel` (`extra="forbid"`); never assign the payload to an attribute, log it, cache it to disk or return it. Pinned by the sentinel tests (log/stdout/repr/DB). |
| T-07.1-11 | Denial of Service | cold-start retry | low | mitigate | Exactly one bounded extra probe; no loop. |
| T-07.1-12 | Spoofing | endpoint branch on the wrong surface | medium | mitigate | Discovery dispatches on the same `detect_surface` verdict as completion; the endpoint tests assert the literal paths so a branch swap fails. |
| T-07.1-SC | Tampering | package installs | high | accept | No package is installed by this plan. |
</threat_model>
