## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest + pytest-asyncio (already in the repo) |
| **Config file** | `pyproject.toml` — `addopts` excludes `not live` (and `not latex`) from the default lane |
| **Quick run command** | `.venv/bin/python -m pytest -q tests/llm/` |
| **Full suite command** | `.venv/bin/python -m pytest -q` |
| **Operator live lane** | `.venv/bin/python -m pytest -q -m live tests/llm/` (or `.venv-host/bin/python` on the host) |
| **Estimated runtime** | quick lane ~a few seconds; live lane depends on server reachability |

---

## Sampling Rate

- **After every task commit:** Run `.venv/bin/python -m pytest -q tests/llm/`
- **After every plan wave:** Run `.venv/bin/python -m pytest -q`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Phase gate:** full suite green; the operator live lane run once and its output pasted into the phase verification notes (D-150)
- **Max feedback latency:** seconds (offline lane; live lane is operator-run, not part of the fast loop)
