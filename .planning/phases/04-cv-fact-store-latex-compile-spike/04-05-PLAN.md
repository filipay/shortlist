### Decisions this plan implements

- **D-59** — import is a **bounded parser plus curation**. `app/cv/import_tex.py` parses the tractable subset (sections, entry macros, bullets) into a draft `cv.yaml` plus an unresolved-items report; a human curates the remainder. - **D-60** — the spike emits an **executable script reporting counts** (sections parsed, entries, unresolved macros, TeX packages requested) plus a written verdict at `docs/probes/2026-09-21-cv-tex-spike.md`, matching the Phase 1 scraper-probe precedent and re-runnable whenever the real CV changes.
- **D-61** — the committed fixture is an awesome-cv-style stand-in built from a named package set plus its own `\newcommand` entry macros, deliberately the macro-heavy case so the measurement is conservative. No third-party template is vendored.
- **D-62** — the verdict is a **partial verdict plus a trigger**. The document states what the stand-in proves in a section clearly separated from an "UNRESOLVED — blocked on the real document" section naming the exact command to run. STATE.md's blocking unknown #1 stays open and is rewritten to point at that trigger. Phase 4 ships; Phase 6 estimation proceeds knowing the measurement is outstanding.
- **D-76** — the TeX Live fallback is **measured once**: the image is built by hand, the fixture compiled through it, and the result recorded in the verdict document. Cost: one slow multi-gigabyte build, once. Gain: "fallback available" becomes a measured fact rather than a written intention.
- **CV-02** — the human-authored LaTeX is read-only for every code path; the importer reads it and writes elsewhere.

### Resolved-at-research details this plan must not re-derive

- The tractable subset is exactly: **sections** (`\section` / `\section*`, and the subsection forms, optionally through a `\newcommand` wrapper the preamble declares); **entry macros** — any macro the preamble declares via `\newcommand{\name}[N]{body}` whose body uses `#1` and at least one of `#2`/`#3`; the parser learns `N` and then captures the next `N` balanced brace groups at each call site — this is the mechanism that makes a macro-heavy résumé tractable without a TeX engine; **bullets** (`\item` inside an itemize or enumerate environment, with balanced-brace capture and inline bold/emph flattened to plain text); **preamble packages** (every `\usepackage` name, collected for the "TeX packages requested" count); and **comments** (percent to end of line, honouring an escaped percent).
- **Everything not on that list is reported, never guessed.** The report is counts-and-names only, in the `SanitizeReport` discipline.
- The parser's bounds are `Settings` fields (`tex_import_max_lines`, `tex_import_max_depth`), so a pathological document cannot hang the single worker.
- The phase's two bundle-coverage checks are concrete commands, not arguments: a bundle **search** per preamble package, and the build-time prime. Both belong in the verdict document's evidence.
- The verdict document's shape is `docs/probes/2026-09-15-scraper-survival.md`'s: a status marker, a clearly separated unresolved section, and the re-runnable command.
- Escalation, if the bounded parser is defeated: the research records **TexSoup** as the documented escalation, not a recommendation. Do not install it speculatively.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| The human's real CV document to the importer | A semi-trusted, locally-authored file the parser reads; it must never be modified, and a field the parser cannot read must not be invented |
| The importer's draft to the reviewed fact store | A machine-written file a human is expected to correct; anything the parser guessed would be indistinguishable from a fact once curated |
| The spike's numbers to a committed document | The verdict is committed, so its content is a disclosure surface: counts and names are safe, document text is not |
| The verdict's claim to its own evidence | A stand-in result presented as a real-document measurement is the project's ethical failure applied to its own evidence |
| The bounded parser to the single worker | A pathological document must not be able to hang the process |
