## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/listings/{id}` | An untrusted path parameter selects a row |
| stored model prose → HTML | A rationale produced from untrusted listing text crosses back into the page |
| stored listing text → HTML | Job-board title, company and location cross back into the page |
| CV fact ids → HTML | Internal CV identifiers are rendered as visible text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12 | Tampering | `listing_detail.html` rendering of title and rationale | high | mitigate | Jinja autoescape only, no `|safe` anywhere in the template; a dedicated test seeds `<script>x</script>` into both the title and the rationale and asserts the escaped form renders with no raw tag. |
| T-05-13 | Tampering | `listing_id` path parameter | medium | mitigate | Typed as `int` by FastAPI, so nothing non-numeric reaches the query; the repository uses bound parameters only. A malformed id yields a 422 from the framework, never SQL. |
| T-05-14 | Information Disclosure | CV fact ids on the detail page | low | accept | The ids are internal stable identifiers (`bul/...`, `exp/...`) rendered as text for the user's own review; the page is behind the `current_user` seam and v1 is single-user local. |
| T-05-15 | Spoofing | external anchors | medium | mitigate | Every external anchor carries `rel="noopener noreferrer"` and only renders when the URL value is truthy; the existing `_http_url` scheme gate in `queue_repo` still applies because the route reuses `read_row`. |
| T-05-16 | Repudiation | save/hide actions on the detail page | low | mitigate | The detail page reuses the exact two-form event block from the queue row, posting the same event types to the same append-only endpoint, so the audit log has one vocabulary. |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | This phase installs no package; assets stay vendored and `tests/test_no_cdn.py` guards it. |
