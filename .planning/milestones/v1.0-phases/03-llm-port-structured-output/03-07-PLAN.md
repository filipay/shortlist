<objective>
Record the finding and ship the counter seam: **the sanitizer's instruction-like flag stops being
discarded and lands on the listing as counts-only evidence, and `_finish()` gains the LLM counters
Phase 5 will write.**

Purpose: two Phase-1/Phase-2 seams were provisioned but never closed. §6.3 requires instruction-like
text to be a *finding to record* — today `_persist_result` computes the report and throws it away.
And `runs.llm_calls` / `runs.llm_tokens` exist with nothing writing them; D-49 forbids an LLM stage in
this phase, so the honest deliverable is the writer seam plus a direct unit test, not a caller.

Output: the `quality_signals` plumbing through the pure domain and the pipeline, the optional queue
badge, the `_finish()` keyword seam, and both tests.

**MVP framing — user story (MVP_MODE active):** **As** the local operator reviewing a queue that came
from untrusted postings, **I want** a listing that tried to instruct the model to be marked as such,
**so that** I can see the attempt and trust the ones that did not.

**Covers:** §6.3's "the flag is persisted on the listing and shown in the UI"; PLAT-02's observability
obligations; D-49's counter seam.
</objective>
