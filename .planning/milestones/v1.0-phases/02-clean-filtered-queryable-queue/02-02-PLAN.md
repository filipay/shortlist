**As a** job-seeker who runs this on my own machine, **I want to** add exactly one reviewed dependency for fuzzy matching and nothing else, **so that** the supply-chain surface of this phase stays a single, human-approved pin.

<objective>
Install and pin `rapidfuzz==3.14.6` — the only new runtime dependency in Phase 2 — behind a blocking human checkpoint, because the package-legitimacy gate returned `SUS`.

Purpose: `rapidfuzz` is the library the project's own `STACK.md` Q4 already selected for Tier-2 dedup, but it is not declared in `pyproject.toml`. Output: the installed wheel, the exact pin in both dependency manifests, and a test that binds the declaration to the installed version.
</objective>
