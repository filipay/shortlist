# Phase 07.1 — API Coverage Matrix

> **Full-coverage baseline.** This phase integrates an external service surface (the opencode
> V2 HTTP API). Every endpoint of that surface which this project's scope **touches** is listed
> below as either `INTEGRATE` or `OPT-OUT` — opt-out is never silent. Endpoints outside the
> project's scope (the remaining ~110 of the 118 paths in the server's `/openapi.json`) are not
> enumerated; the project consumes exactly the surface below.
>
> Detector: `api-coverage.cjs --json` returned `detected:true` on the phase scope
> (`signals: integrate/api, integrate/endpoints`).
>
> Scope source: `07.1-CONTEXT.md` (in scope: the wire contract — both API surfaces + detection),
> `07.1-RESEARCH.md` ("Code Examples", "State of the Art").

## V2 surface (opencode 2.0.x — new; D-147)

| Endpoint | Method | Disposition | Where | Reason (for OPT-OUT) |
|----------|--------|-------------|-------|----------------------|
| `/api/info` | GET | **INTEGRATE** | `app/llm/detection.py`, `app/llm/opencode_server.py::health` | Liveness + the running server version (D-137/D-150); the V2 detection signal. |
| `/api/model` | GET | **INTEGRATE** | `app/llm/opencode_server.py::discover_models` | Model discovery, retargeted (D-146); carries `modelID` + `providerID`. |
| `/api/provider` | GET | **INTEGRATE** | `app/llm/opencode_server.py::discover_models` | Provider discovery, retargeted (D-146); identifiers only, never the credential. |
| `/api/session` | POST | **INTEGRATE** | `app/llm/builders.to_v2_session_body`, `opencode_server` | Session create with `model: Model.Ref {id, providerID}` (a bare string is a 400 — Pitfall P1). |
| `/api/session/{sessionID}/generate` | POST | **INTEGRATE** | `app/llm/builders.to_generate_body`, `opencode_server` | The completion call (`{prompt}` -> `{data:{text}}`). Chosen because it has no tool-execution surface (locked; 07.1-CONTEXT). |
| `/openapi.json` | GET | **INTEGRATE** | `tests/llm/test_contract_live.py` (operator lane) | The authoritative contract document for the live diff (D-150); auth required (Pitfall P8). |
| `/api/pair` | POST | **INTEGRATE (operator procedure)** | `docs/runbook-opencode-contract.md` | The documented pairing flow the operator runs to obtain the password (D-135). Not called by app code. |
| `/auth/connect/{code}` | GET | **INTEGRATE (operator procedure)** | `docs/runbook-opencode-contract.md` | Returns the session token used as `OPENCODE_SERVER_PASSWORD` (D-135). Not called by app code. |
| `/api/session/{sessionID}/prompt` | POST | **OPT-OUT** | — | Carries `files`/`agents`/`skills`/`delivery`/`resume` — a tool-execution surface (the standing STACK.md injection threat). `generate` is used instead. |
| `/api/session/{sessionID}/message` | GET | **OPT-OUT** | — | Reads a session's messages; this app is stateless w.r.t. sessions (one session per call) and needs no read-back. |
| `/api/session/{sessionID}` (and other session mutation/read paths) | GET/DELETE/PATCH | **OPT-OUT** | — | Sessions are created and discarded per call; no lifecycle management is needed. |
| Session permission/tool endpoints and the V2 `Permission.Rule` shape | any | **OPT-OUT** | — | `generate` has no tool surface, so no permission ruleset is needed (the V1 `permission` ruleset is deliberately not sent on the V2 session body). |
| File/PTY/agent/skill/model-registry mutation endpoints | any | **OPT-OUT** | — | Out of scope for a contract migration; no new capability is added by this phase. |

## Not-integrated surfaces (explicit)

| Surface | Disposition | Reason |
|---------|-------------|--------|
| V1 `permission` ruleset / `DEFAULT_DENY_RULES` | **OPT-OUT on the V2 path; retained on V1** | V2 `generate` accepts only `{prompt}`, so there is nothing to deny. The V1 ruleset is retained unchanged for the V1 branch. |
| V2 SSE `/event` stream | **OPT-OUT** | No streaming progress surface is in this phase's scope (the pipeline calls are synchronous `generate` calls). |
| Any hosted/other-openapi-version surface | **OPT-OUT** | The contract test + runbook pin the supported server version; an unknown surface fails detection as `unknown` rather than being guessed at. |

## Coverage verdict

- **V2 endpoints this project consumes:** 8 (6 in app code + 2 operator-only) — all INTEGRATE.
- **V2 endpoints deliberately not used:** 5 groups — all OPT-OUT with a stated reason.
- **V1 endpoints retained:** 4 — all INTEGRATE via the retained dual-support path; 2 OPT-OUT with a stated reason.
- No endpoint in this project's scope is left unclassified.
