## Accomplishments

- Added the V2 contract group to `contract.py` (13 new constants) alongside the retained V1 group, plus the pure builders `to_v2_session_body` (a `Model.Ref` object, never a bare string) and `to_generate_prompt`/`to_generate_body`.
- New `app/llm/detection.py`: a pure `classify_surface`, an async `detect_surface` probing `/api/info` then `/global/health`, and a process-local verdict cache that never caches `unknown`. The SPA-200 false positive is fixed (`health()` no longer reports a `text/html` 200 as reachable).
- `OpenCodeServerBackend.complete_structured` dispatches on the detected surface: the V2 arm creates a session, issues `generate`, extracts JSON from the model's prose, salvages it, and retries a pydantic failure with the first error fed back, bounded to `1 + opencode_structured_retry_count` requests.
- `ERROR_KIND_UNAUTHENTICATED` (D-137); an empty configured password fails fast with zero requests (D-136); any V2 `401` classifies as `unauthenticated`.
- V2 telemetry (D-143/D-144): `llm_calls.model` records the requested model, provider/agent/tokens are `None`, `server_version` comes from `/api/info`.

## Decisions Made

- **`classify_surface` orders `healthy` before `version`.** A V1 `/global/health` body carries BOTH keys; checking `version` first would misclassify every V1 server as V2. The plan listed V2-then-V1, but the correct discriminator is `healthy` for V1.
- **Detection cache is result-based only** (no TTL, no in-flight dedup — the plan explicitly permitted this), and it never stores an `unknown` verdict so a late-starting server is still detectable (RESEARCH A2).
- **`GLOBAL_HEALTH_PATH` moved into `contract.py`.** It is a wire name (D-54's single home), and `detection.py` needs it without importing `opencode_server` (import cycle). `opencode_server` re-exports it, so existing importers are unaffected.
