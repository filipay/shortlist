<objective>
Close G-07-3: make the grounding findings the checker already computes survive to the human, and surface the advisory band as advisory.

The persist path keeps only the `unsupported` boolean plus the already-grounded `evidence_json`; the offending id was dropped from that set, so once the verdict is discarded the information is gone. The template can therefore only emit a fixed generic line. The phase's verified requirement (VERIFICATION row 13, "naming the id") has no human-visible surface.
Output: migration 0007 for the two new nullable columns, the repository/model/pipeline/render plumbing, the UI-SPEC amendment, and a rendering test that names the offender.
</objective>
