<objective>
Close CR-01: a valid-but-PARTIAL drafting response must not delete the user's unanswered stored drafts.

Purpose: `app/api/apply.py::draft_answers` distinguishes only "no verdicts" (`drafting_failed`) from "some verdicts" (`drafting_empty`). Any non-empty partial list falls through to `screening_draft_repo.replace_for_listing`, whose first act is `DELETE` every `screening_drafts` row for the listing. Because `ground_screening_answers` emits one verdict per *answer* (positional `zip(..., strict=False)`, `app/verify/screening.py:108`), a realistic response covering a subset of the asked questions silently drops every row the model did not answer — including ad-hoc questions the user typed, whose text exists nowhere else. The verifier reproduced this deterministically (3 seeded ad-hoc rows -> 1 row remained after a one-answer POST). The route's own copy ("Your existing drafts were kept.") is false on this path.

Output: a third refusal (`drafting_partial`) that returns before any delete, plus the regression test that locks the survival of unanswered rows.
</objective>
